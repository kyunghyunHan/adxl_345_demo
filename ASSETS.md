# Asset provenance

## assets/models/aircraft.glb

- Title: **Narrow-body airliner**
- Author/source: Innerscene, original unbranded geometry and materials.
- Source page: https://www.innerscene.com/tools/library/3d-parts/narrow-body-airliner-8c1aee2c
- Download: https://www.innerscene.com/api/library/narrow-body-airliner-8c1aee2c/download
- License: **CC0-1.0 / public domain**. The source page explicitly permits use, modification and redistribution for any purpose, including commercial use. The GLB root extras also declare `CC0-1.0` and `Innerscene original CC0 geometry`.
- License text: https://creativecommons.org/publicdomain/zero/1.0/legalcode
- License checked and downloaded: 2026-11-16.
- File: 6,652,484 bytes, glTF binary version 2. Embedded PNG textures; no external texture requests.
- Modifications: none to the file. Runtime child transform rotates +90° about Y, scales by 0.18, and translates Y by −0.747 to put the fuselage centerline at the attitude pivot.
- Native axes: nose +X, up +Y, right wing +Z. Overall bounds: X ±18.77744m, Y 0–10.09750m, Z ±17.08120m.

Other requested candidates were reviewed: the Innerscene regional jet also advertises CC0; Lakshya's library advertises personal/commercial use but no static model list was available through the inspected page. The first-priority CC0 airliner was selected and bundled locally.

UI, reference grid, and instrument markings are generated by this project's Rust code.  No generated raster art is used.
